# Security policy

## Supported versions

Fixes go into the latest release only. While the module is at v0, a fix may
come with other changes, as v0 makes no compatibility promise.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: on the
[Security tab](https://github.com/uma-31/inoreader-go/security), choose
**Report a vulnerability**. Do not open a public issue.

Include what is affected, how to reproduce it and what an attacker could do.
Leave out any real Inoreader credentials or tokens; a reproduction against
the mock server in `e2e/mock` is enough.

This is a personal project, so reports are handled on a best-effort basis.
Once a fix is released, the advisory is published with credit to the
reporter, unless they ask otherwise.
